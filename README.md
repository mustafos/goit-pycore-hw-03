# GOIT Python Core — Homework 03

## Description

This project contains four Python functions:

1. `get_days_from_today(date)` — calculates the number of days between a given date and today.
2. `get_numbers_ticket(min_value, max_value, quantity)` — generates unique, sorted lottery numbers.
3. `normalize_phone(phone_number)` — normalizes Ukrainian phone numbers to the international format.
4. `get_upcoming_birthdays(users)` — finds upcoming birthdays and moves weekend congratulations to Monday.

## Requirements

- Python 3

No external dependencies are required.

## Run

```bash
python3 main.py
```
